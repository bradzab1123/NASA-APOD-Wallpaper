# NASA Astronomy Picture of the Day Wallpaper Script

Automatically fetches NASA's Astronomy Picture of the Day (APOD) and sets it as your desktop wallpaper. Works on both Windows and macOS.

## What's in this repo

- `apod_wallpaper.py` — the main script
- `requirements.txt` — Python packages needed to run it
- `.env.example` — template for your NASA API key; copy this to `.env` and fill in your own key
- `LICENSE` — usage terms
- `README.md` — this file

## Before you start

You'll need Python installed (3.9 or later recommended). Grab it free at [python.org](https://www.python.org/downloads/) if you don't have it — on Windows, check the box that says "Add Python to PATH" during install.

You'll also need a free NASA API key, available at [api.nasa.gov](https://api.nasa.gov/).
